## 支援版本

本 repo 為樣板專案，目前僅維護 `main` 分支的最新版本。

## 回報漏洞

請勿透過公開 Issue 揭露漏洞細節，以免在修補完成前遭到利用。

請使用 GitHub 的私人漏洞回報功能。進入 **Security** 頁籤後，選擇 **Report a vulnerability**。

回報時請盡可能提供以下資訊：

- 漏洞類型，以及受影響的檔案或相依性套件與版本
- 重現步驟（Steps to Reproduce）或概念驗證（Proof of Concept, PoC）
- 漏洞可能造成的影響

收到回報後，會進行評估；確認漏洞後將盡快著手修補。

## 回報範圍

- 範圍內：本 repo 維護的程式碼與設定。
- 範圍外：上游相依性套件（如 `@line/liff`、`lit`）本身的漏洞，請直接向對應的上游專案回報。
