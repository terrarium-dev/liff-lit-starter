# Security Policy

🌐 **English** | [臺灣正體中文](docs/SECURITY.zh-TW.md)

## Supported Versions

This is a template repository. Only the latest state of the `main` branch is supported.

## Reporting a Vulnerability

Do not disclose vulnerability details in public GitHub issues to prevent exploitation before a fix is available.

Use GitHub's private vulnerability reporting feature. Under the **Security** tab, select **Report a vulnerability**.

Please include the following information where possible:

- Vulnerability type and affected files or dependencies, including their versions
- Steps to reproduce the issue or a proof of concept (PoC)
- Potential impact

Reports will be reviewed, and confirmed vulnerabilities will be addressed promptly.

## Scope

- In scope: code and configuration maintained in this repository.
- Out of scope: vulnerabilities in upstream dependencies (e.g., `@line/liff` and `lit`). Please report these directly to the respective upstream projects.
